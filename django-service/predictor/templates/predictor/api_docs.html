The Training API runs on port 8000 and exposes the following endpoints. Base URL: {{ api_url }}

POST /predict

Submit property features and receive an estimated price. The model must be loaded for this endpoint to respond.

Request Body

FieldTypeRequiredDescription
BedroomsintYesNumber of bedrooms (1–10)
BathroomsintYesNumber of bathrooms (1–5)
SquareFeetfloatYesLiving area in square feet
LocationstringYesCity name

Example

{ "Bedrooms": 3, "Bathrooms": 2, "SquareFeet": 1800, "Location": "New York" }

Response

{ "prediction": 345200.50, "model_version": "housing_price_predictor_20260219_110919", "features_used": ["Bedrooms", "Bathrooms", "SquareFeet", "Location"] }
POST /train

Trigger model retraining using the latest dataset. The model is automatically reloaded after training completes.

Response

{ "status": "success", "metrics": { "r2": 0.86, "mae": 45230.12, "rmse": 58102.44 }, "timestamp": "20260219_110919", "model_path": "/app/models/artifacts/housing_price_predictor_20260219_110919.joblib" }
GET /metrics

Returns the current model's performance metrics, hyperparameters, and feature list. Used by the Dashboard page to display live model information.

Response

{ "metrics": { "r2": 0.86, "mae": 45230.12, "rmse": 58102.44 }, "timestamp": "20260219_110919", "model_params": { "n_estimators": 200, "max_depth": 20 }, "features": ["Bedrooms", "Bathrooms", "SquareFeet", "Location_encoded"] }
GET /health

Health check endpoint. Reports service status and whether a model is currently loaded in memory.

Response

{ "status": "healthy", "model_loaded": true }
